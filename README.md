# 番茄钟

一款简洁高效的桌面番茄钟应用，帮助你专注工作、管理任务、追踪时间。

## 功能

- **番茄计时**：25 分钟工作 + 5 分钟休息，可自定义时长和轮次
- **任务管理**：添加任务、标记完成、关联番茄数
- **历史记录**：每日工时统计、累计番茄数、详细时间线
- **系统托盘**：最小化到托盘，后台运行不打扰
- **桌面通知**：工作和休息结束时弹出通知
- **键盘快捷键**：空格（开始/暂停）、R（重置）、S（跳过）
- **窗口置顶**：保持计时器始终可见

## 安装与运行

确保已安装 Node.js 18+。

```bash
npm install
npm start
```

## 开发

```bash
npm install       # 安装依赖
npm start         # 启动应用
npm run lint      # 代码检查
npm run format    # 代码格式化
npm test          # 运行测试
```

## 打包

```bash
npm run pack      # 本地打包（输出到 dist/）
npm run build     # 生产打包
```
